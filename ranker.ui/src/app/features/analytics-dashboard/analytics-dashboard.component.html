Google Analytics 4 API Setup

Connect your GA4 Property to stream real-time production telemetry
1

Client Tracking Tag Configured

Your website is already collecting traffic via Google Tag: G-G5F28SY0F0 embedded in src/index.html.

2

Find Your GA4 Property ID

In Google Analytics, go to: Admin ⚙️ → Property Settings → Property Details. Copy the numeric Property ID (e.g. 475829103).

3

Create a Service Account in Google Cloud

  1. Go to Google Cloud Console.
  2. Enable the Google Analytics Data API (v1beta).
  3. Under IAM & Admin → Service Accounts, create a service account (e.g. ga-reader@project.iam.gserviceaccount.com).
  4. Create a JSON Key and download it.
  5. In Google Analytics Admin → Property Access Management, add this service account email with the Viewer role.
4

Add Credentials to RankUp Backend

In backend/ranker/appsettings.json, fill in the GoogleAnalytics section:

"GoogleAnalytics": {
  "PropertyId": "YOUR_NUMERIC_GA4_PROPERTY_ID",
  "CredentialsFilePath": "C:\\path\\to\\service-account.json"
}

Or on Linux / Docker, set environment variables: GOOGLEANALYTICS__PROPERTYID and GOOGLEANALYTICS__CREDENTIALSFILEPATH.
